# RPG_Warrior
An RPG game developed with UE5 C++, using Gameplay Ability System (GAS).

Aspects of GAS used include:
- Gameplay Ability
- Gameplay Effect
- Attribute Set
- Gameplay Effect Execution Calculation

Other Components/Systems used:
- Anim Instance
- Linked Anim Blueprint
- Motion Warping
- AI (Controller, Behaviour Tree, BlackBoard, BTTask, BTDecorator, BTService, EQS)
- Widgets

Code Architecture
- Inheritance
- Components
- Interfaces
- Data Assets
